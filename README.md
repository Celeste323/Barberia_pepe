## Descripción
Sistema web para una barbería que permite mostrar servicios, horarios y una experiencia de navegación moderna para los clientes.

## Comandos para levantar el proyecto

```bash
git clone https://github.com/Braian436/web_pepe.git
npm install
npm run dev
```
